# Operation-System-s-Task
4 question.

1. Архетиктуры прав доступа. 
В Linux разделение root и обычного пользователя
 куда строже, чем на Win. В Win пользователи чаще
 работают с правами администратора по-умолчанию, что облегчало заражение.

2. Дистрибутивы.
У Linux существуют разные дистрибутивы, ядра и пакетные
 менеджеры (apt, dnf, pacman...), вирусу сложнее быть универсальным.
 Win в этом плане гараздо проще.

3. Источники ПО.
Пользователи Linux чаще ставят программы с оффициальных
 репозиториев, а не скачивают случайные .exe файлы, как на Вин.

4. Аудитория.
На Linux пользователи часто более технологически подкованны,
 что заметно снижает вероятность случайного заражения.

5. Популярность.
Популярность действительно играет большую роль, если речь про десктопы.
 Тк большенство вирусов создаётся для массового заражения с целью кражи денег, майнинга или ботнетов.
 Чем больше пользователей, тем больше жертв.

Важная оговорка: 
На серверах(где Linux доминирует) вредоносного ПО и атак довольно много,
 просто оно нацелено на другое. Эксплуатация уязвимостей в веб-сервисах, майнеры, кража данных. 
 Так что "неуязвимость" Linux сильно преувеличена, это, скорее, другой профиль угроз, чем их отсутствие.
